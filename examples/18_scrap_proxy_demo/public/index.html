Example 18: Web Scraping Proxy Demo

This example fetches books.toscrape.com with an HTTP Custom Type, then proxies the scraped HTML to an upstream service which parses it and returns the average book price on the page.

The scraped HTML is forwarded into the proxy request body with @body_parameter_name — too large for the query string — while the small HTTP-type fields ride the query string. The upstream service reads each price from <p class="price_color"> (e.g. £51.77) and averages them.
